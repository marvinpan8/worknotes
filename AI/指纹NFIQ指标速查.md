# NFIQ 指纹图像质量评估指标速查表

**参考标准**: NFIQ 2.0 (NIST Fingerprint Image Quality)，是国际标准 **ISO/IEC 29794-4:2024**（指纹图像数据质量）的官方参考实现，其质量指标也被 **ISO/IEC 39794-2:2023** 所采用

## 一、硬性指标 ⭐

| Column                              | 描述 (Description)           | 建议阈值 / 合格标准                                          |
| ----------------------------------- | ---------------------------- | ------------------------------------------------------------ |
| `NFIQ2`                             | NFIQ 2.0 质量分数            | **>=41** |
| `fingerprint_image_with_minutiae`   | 图像中提取到的细节特征点数量 | **≥ 40**（优质指纹通常 ≥ 50）                                |
| `sufficient_fingerprint_foreground` | 有效指纹前景像素数量         | **≥ 50000**                                                  |
| `quantized`                         | 图像是否被量化压缩           | **= 0**（1 表示图像经过量化，可能损失细节）                  |
| `resampled`                       | 图像是否被重采样         | **= 0**（1 表示经过重采样，可能影响分辨率）   |
| `empty_image_or_contrast_too_low` | 空白图像或对比度过低检测 | **> 100**（低于阈值表示图像空白或对比度不足） |

## 二、建议指标

| Column          | 描述 (Description)             | 建议阈值 / 合格标准              |
| --------------- | ------------------------------ | -------------------------------- |
| `uniform_image` | 图像灰度均匀度（标准差）       | **≤ 80**（越低表示背景越均匀）   |
| `edge_std`      | 边缘梯度标准差（识别畸形图像） | **≥ 20**（值越高表示边缘越清晰） |

## 三、辅助指标

| Column         | 描述 (Description)     | 建议阈值 / 合格标准 |
| -------------- | ---------------------- | ------------------- |
| `image_width`  | 输入图像宽度（像素）   | ≥ 300               |
| `image_height` | 输入图像高度（像素）   | ≥ 400               |
| `log`          | 处理日志（格式转换等） | 仅参考，无阈值      |
