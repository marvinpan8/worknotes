# BQAT 人脸图像质量评估指标速查表

- https://docs.bqat.io/modality/face.html
- https://docs.bqat.io/modality/fingerprint.html

## 一、硬性指标 ⭐

| Column         | 描述 (Description)     | 建议阈值 / 合格标准 |
| -------------- | ---------------------- | ------------------- |
| `image_width`  | 输入图像的宽度（像素） | 建议 ≥ 600          |
| `image_height` | 输入图像的高度（像素） | 建议 ≥ 800          |
| `smile`            | 是否检测到微笑     | **false**（必须为否） |
| `glasses`          | 是否检测到眼镜     | **false**（必须为否） |
| `eye_closed_left`  | 左眼是否闭合       | **false**（必须为否） |
| `eye_closed_right` | 右眼是否闭合       | **false**（必须为否） |
| `face_detection` | 人脸检测置信度               | **≥ 0.80**（低于此值可能未检测到人脸） |
| `yaw_pose`     | 头部姿态中的偏航角方向 | 应为 `"forward"`    |
| `yaw_degree`   | 左右转头角度           | **绝对值 ≤ 10°**    |
| `pitch_pose`   | 头部姿态中的俯仰角方向 | 应为 `"level"`      |
| `pitch_degree` | 上下仰头角度           | **绝对值 ≤ 10°**    |
| `roll_pose`    | 头部姿态中的翻滚角方向 | 应为 `"level"`      |
| `roll_degree`  | 头部倾斜角度           | **绝对值 ≤ 5°**     |

## 四、建议指标

| Column                | 描述 (Description)   | 建议阈值 / 合格标准                 |
| --------------------- | -------------------- | ----------------------------------- |
| `face_ratio`     | 人脸面积占整个图像的比例     | **≥ 0.35**（ICAO 建议约 50-80%）       |
| `sharpness`           | 锐度/清晰度    | **≥ 50**（严格场景 ≥ 80）           |
| `brightness`          | 亮度       | **80 ~ 180**（过暗或过亮均不合格）  |
| `contrast`            | 对比度         | **≥ 50**（过低表示图像发灰）   |
| `dynamic_range`       | 动态范围     | **≥ 150**（越高表示明暗层次越丰富）|
| `face_offset_x` | 人脸中心水平偏移量   | **绝对值 ≤ 0.15**（越接近 0 越居中） |
| `face_offset_y` | 人脸中心垂直偏移量   | **绝对值 ≤ 0.15**（越接近 0 越居中） |


## 三、辅助指标

| Column           | 描述 (Description)           | 建议阈值 / 合格标准                    |
| ---------------- | ---------------------------- | -------------------------------------- |
| `ipd`           | 瞳孔间距（像素）     | **通常 ≥ 80**，用于辅助判断人脸大小|
| `pupil_right_x` | 右瞳孔 X 坐标（像素） | 用于计算 `ipd`，无直接阈值 |
| `pupil_right_y` | 右瞳孔 Y 坐标（像素） | 用于计算，无直接阈值       |
| `pupil_left_x`  | 左瞳孔 X 坐标（像素） | 用于计算 `ipd`，无直接阈值 |
| `pupil_left_y`  | 左瞳孔 Y 坐标（像素） | 用于计算，无直接阈值       |
| `bbox_left`      | 人脸边界框左边界坐标（像素） | 用于计算，无直接阈值 |
| `bbox_upper`     | 人脸边界框上边界坐标（像素） | 用于计算，无直接阈值 |
| `bbox_right`     | 人脸边界框右边界坐标（像素） | 用于计算，无直接阈值 |
| `bbox_lower`    | 人脸边界框下边界坐标（像素） | 用于计算，无直接阈值 |
| `head_top`      | 头部位置估计的上边界 | 用于计算，无直接阈值     |
| `head_bottom`   | 头部位置估计的下边界 | 用于计算，无直接阈值     |
| `head_right`    | 头部位置估计的右边界 | 用于计算，无直接阈值     |
| `head_left`     | 头部位置估计的左边界 | 用于计算，无直接阈值     |
